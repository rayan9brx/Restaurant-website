# Restaurant frontend

A minimal React/Vite welcome page.

## Run locally

```powershell
npm install
npm run dev
```

Open the URL printed by Vite, normally http://localhost:5173.

The development proxy forwards /api requests to http://localhost:8080 for future steps. The welcome page does not make API requests and runs without the backend.

## Build

```powershell
npm run build
```
